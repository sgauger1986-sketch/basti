# Free LLM APIs

Source: https://github.com/open-free-llm-api/awesome-freellm-apis (snapshot 058cc76, 2026-10-01). Live data: https://freellm.net

1. Read `references/README.md` for the provider and model tables, limits and signup notes.
2. Use `references/code-examples/` for ready-made client snippets.
3. The upstream list refreshes daily. Before recommending a provider for real use, check https://freellm.net/models/ (or the upstream README) for current limits, and tell the user the snapshot date if you could not.
4. Never commit API keys; point the user to environment variables or the environment's secret settings.
